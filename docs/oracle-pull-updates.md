## Implementation notes from the installed runtime

The installed pg-boss 12.38.0 offWork(name, {wait:true}) stops polling and awaits each worker's run promise. A fetch already in flight can still enter its callback, so the update readiness signal must wait for all offWork promises, not just an active counter. The existing active counter currently tracks applications only, not ingestion/scheduler; drain all registered consumers. Resuming must not register duplicate consumers while an earlier stop is unfinished. Standby resume must not start consumers. Keep the worker's acceptance configuration immutable; drain is an authenticated temporary in-memory state, not a cutover switch.
