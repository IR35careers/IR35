# IR35Careers Application Assistant

This Manifest V3 extension continues an application that the signed-in contractor has already reviewed and approved in IR35Careers. A one-hour, one-application token opens the real employer page. The extension can create or sign in to an employer account using the contractor's private IR35Careers address, upload the approved CV, fill saved profile facts and approved answers, and capture the employer confirmation.

The assistant activates only in the employer tab opened by IR35Careers. It does not scan browsing history or unrelated tabs. CAPTCHA, identity checks and new employer declarations stay under the contractor's control. Missing questions are highlighted directly on the employer page and saved back to the IR35Careers application.

Until a Chrome Web Store review is completed, load the folder through `chrome://extensions` → **Developer mode** → **Load unpacked**, or use the downloadable ZIP published by the website.
