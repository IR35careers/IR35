# IR35Careers Chrome helper

This Manifest V3 extension uses only `activeTab`. It reads the current tab URL after the user presses **Analyse current job**, then opens the public IR35Careers external-job analyser. It does not read page content, credentials, form fields, cookies or browsing history and it cannot submit applications.

Until a Chrome Web Store review is completed, load the folder through `chrome://extensions` → **Developer mode** → **Load unpacked**, or use the downloadable ZIP published by the website.
